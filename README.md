<h2>Название проекта:</h2>
<p>Локальная интерполяция многочленами Лагранжа</p>

<h2>Описание</h2>
<p>Программа на C++ строит локальную интерполяцию функции f(x) = sin(x) на отрезке [a, b] с помощью кусочно-полиномиальной интерполяции Лагранжа. Отрезок разбивается на K равных интервалов, на каждом интервале строится интерполяционный полином степени (N-1) по N равноудалённым узлам. Вычисляются абсолютная и относительная погрешности в нормах L1, L2, L∞ на сетке с шагом h/100. Визуализация выполняется с помощью Python (matplotlib).</p>

<h2>Что происходит при запуске</h2>
<ol>
<li>Генерируется равномерная сетка из M узлов интерполяции (M = K*(N-1)+1).</li>
<li>Для каждого из K отрезков строится интерполяционный полином Лагранжа по N узлам.</li>
<li>Вычисляются значения полинома в M_viz точках для визуализации.</li>
<li>На более частой сетке (шаг h/100) вычисляются погрешности:</li>
<ul>
  <li>Абсолютная и относительная погрешности в норме L1 (сумма модулей)</li>
  <li>Абсолютная и относительная погрешности в норме L2 (корень из суммы квадратов)</li>
  <li>Абсолютная и относительная погрешности в норме L∞ (максимум модуля)</li>
</ul>
<li>Результаты погрешностей выводятся в консоль.</li>
<li>Данные для графиков сохраняются в <code>data/parameters.txt</code>.</li>
<li>Автоматически запускается Python скрипт <code>scripts/create_plot.py</code>, который строит графики f(x) и L(x).</li>
</ol>

<h2>Визуализация</h2>
<p>После расчётов появляется окно с двумя графиками: синим пунктиром – исходная функция f(x), чёрной сплошной линией – интерполяция L(x). Узлы интерполяции отмечены кружками. Сетка и легенда включены.</p>
